Universal Data Ingestion
Every format your site actually uses
Import from Epic, Cerner, MEDITECH, Athena, or any EMR. Auto-detects format, maps columns intelligently, and deduplicates records — no manual configuration required.

CSV / TSV / Excel

The universal EMR export

Pipe-delimited, tab-separated, comma-separated, multi-sheet Excel workbooks — all auto-detected. Smart column mapping recognizes MRN, DOB, ICD-10, medications, labs, and 40+ clinical fields.

.csv .tsv .xlsx .xls .pip .dat
Works with: Epic, Cerner, MEDITECH, Athena, eCW, NextGen, Allscripts

FHIR R4 JSON Bundles

Modern interoperability standard

Full FHIR R4 Bundle parsing — Patient, Condition, Observation, MedicationRequest, Procedure, and AllergyIntolerance resources. Extracts ICD-10, LOINC, RxNorm, and CPT codes automatically.

{ "resourceType": "Bundle", "type": "collection", "entry": [{ "resource": { "resourceType": "Patient", "id": "pat-001" // ← auto-linked } }] }
.json .ndjson

HL7 v2 Messages

Hospital interface feeds

Parse ADT, ORU, SIU, and batch message files. Extracts demographics (PID), diagnoses (DG1), labs & vitals (OBX), medications (RXA/RXE), and allergies (AL1). Merges multiple messages per patient.
