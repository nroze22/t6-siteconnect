Core Capabilities

Three things no one else does together

AI-Powered Screening

Two-tier engine: deterministic rules for structured criteria, local LLM (BioMistral-7B) for complex clinical judgments. Every result linked to source evidence.

  • Rule-based: age, ICD-10, labs, medications
  • LLM: ECOG, clinical notes, complex I/E
  • Graceful fallback if LLM unavailable
  • All inference runs locally on CPU

Financial Intelligence

CMS-anchored per-patient value estimates, three-scenario modeling, and an interactive budget wizard. Sites see the money before they commit.

  • CMS 2025 fee schedule benchmarks
  • Conservative / base / optimistic scenarios
  • Editable line-item overrides in real-time
  • Break-even analysis per study

Zero-Trust Security

Fully on-premise. AES-256 encrypted database. No cloud, no PHI transmission, no IT integration required. Passphrase-protected with tamper-evident audit trail.

  • SQLCipher AES-256 encryption at rest
  • Zero network PHI transmission
  • Cryptographic audit chain
  • HIPAA preparatory research compliant
