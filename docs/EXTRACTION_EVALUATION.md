This old metric checks values, not complete clinical correctness.

The new evaluation.ts scorer requires exact field, kind, label, value, unit, subject, assertion and annotated source span, independently validates verbatim grounding, matches predictions one-to-one, rejects duplicated gold facts and reports unmatched predictions/missing gold. Empty denominators are null. Seven regressions cover wrong patient/field/assertion/unit, fabricated locations, duplicates, broad duplicate evidence and invalid gold.

`node scripts/score-recall-evidence.mjs` rescored the saved actual built-in-note inference without calling the model again. `docs/extraction-evidence/note-strict-latest.json` records its input hash and explicit gold annotations.
